# Ledger financier — NON IMPLÉMENTÉ

Réservé aux écritures comptables (wallets, ledger_entries, payouts,
remboursements). Ne pas implémenter avant le module Paiements et sans
validation explicite préalable.

Règle centrale déjà actée : solde disponible et solde en attente
toujours séparés ; aucune écriture n'est jamais modifiée après coup,
uniquement des écritures correctives.
