# Anciennes migrations Revant — archive uniquement

Ces fichiers `0001` à `0011` décrivent une première architecture historique du prototype Revant. Ils ne correspondent pas à l'historique de migrations enregistré dans le projet Supabase Revant actuel et contiennent notamment un ancien modèle `orders`/`products` incompatible avec le schéma courant.

Ils sont conservés pour la traçabilité et pour expliquer certaines contraintes historiques du code. **Ne pas les déplacer dans `supabase/migrations` et ne pas les exécuter sur le projet Revant actuel.**

Le schéma actuel doit être géré uniquement à partir des versions réconciliées dans `supabase/migrations` et de l'historique réel retourné par Supabase.
